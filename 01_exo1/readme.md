# WEB API

- Interface

Contrat définit par une entité qui décrit et permet à une autre entité de l'utiliser

- API

Aplication Programming interface

Permet à un programme d'utiliser un autre programme

- WEB API

API contactable au travers du web

- WEB API REST

WEB api qui respecte certaines conventions

    - HTTP
        protocole de communication WEB
        - verb http et code d'erreur en adequation avec le type de fonctionnalité
        - staless

        - Request
